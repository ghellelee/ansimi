## 1. 산출물 패키지 구조

하나의 원자료 세트에서 5개 산출물이 나온다. 재작업 없이 재구성만 하는 구조.

```
[원자료]
전문가 인터뷰(녹취·코딩 11테마/38코드/96발화·서면답변·현장사진 5개 재난)
대피소 탐방 디지털 기록(페르소나별 경로·이슈로그)
데이터화 후보목록 v2

        ↓ 재구성

① 데이터 항목 제안서  ←── 정책·연구용 핵심 산출물, 논문의 뼈대
② 시민용 가이드/리플릿 ←── 지원서에서 약속한 결과물
③ 웹 콘텐츠           ←── ①②를 안심이 웹사이트에 공개
④ 결과보고서          ←── ①②③을 활동 서사로 묶음
⑤ 결과공유회 발표 PPT  ←── ④의 발표 버전
```

## 2. 산출물별 정의

### ① 시민 관점 대피소 데이터 항목 제안서 (핵심)

- **형식**: docx/pdf, 15~25쪽
- **목차(안)**
  1. 배경: "대피소는 주소밖에 없다" — 문제 진단
  2. 방법: 시민 탐방(페르소나 프로브) + 전문가 인터뷰(주제별 코딩)
  3. 제안 데이터 항목: 후보목록 v2를 분류별(시설·접근성 / 생활 / 돌봄 / 반려동물 / 담당주체·연락처 / 실시간)로 정리, 각 항목에 인터뷰 근거·현장 근거·우선순위·수집 난이도 표기
  4. 핵심 원칙 3가지: 결손정보의 명시("없으면 없다고"), 담당주체 데이터화, 재난유형별 분리(사회재난 vs 자연재난)
  5. 지속가능 조건: 평시 관리 체계, 시설관리자·지역사회 공동 갱신
- **원자료**: `안심이_대피소_데이터화후보목록_v2.xlsx`, 코딩분석보고서, 인터뷰 답변(안), 탐방 기록

### ② 우리 동네 대피소 이용 가이드 (약속 이행)

- **형식**: 리플릿(인쇄용 PDF) + SNS 카드뉴스 (예산: 디자인 23만 + 인쇄·카드뉴스 15만)
- **구성**: 프로젝트 소개 / 우리 동네 대피소 지도 / 탐방 기록 하이라이트 / 시민용 대피소 체크리스트("가기 전 확인할 것") / 재난 대비 팁
- **톤**: "내 상황에서 이용 가능한가"를 스스로 확인하게 하는 체크리스트 중심

### ③ 웹 콘텐츠

- 기존 안심이 웹사이트(정적 HTML)에 당옆공 결과 페이지 추가
- 탐방 기록 + 지도 + 가이드 + 제안서 다운로드 링크
- 타임라인에 당옆공 항목 추가

### ④ 결과보고서

- **⚠ 센터 지정 양식 확인 필요** — 확인 전까지 내용 초안만 작성
- **구성(안)**: 활동 개요(4회차) → 회차별 기록 → 결과물 소개(①②③) → 성과와 배움(전문가 인터뷰 인사이트 요약) → 향후 계획(논문·데이터 제안 후속)

### ⑤ 결과공유회 발표 PPT

- 10~15장 내외. 스토리라인: "지도 속 대피소를 직접 가봤다 → 주소밖에 없었다 → 전문가에게 물었다 → 무엇을 데이터화해야 하는지 목록을 만들었다"
- 현장사진(5개 재난) + 탐방 사진을 시각 자산으로 활용

## 4. 하반기 논문 계획 (질적연구)

- **가제**: "시민 참여 탐방과 전문가 인터뷰를 통한 대피소 공공데이터 개선 항목 도출 — 재난약자 관점을 중심으로"
- **RQ**: 현행 대피소 공공데이터는 재난약자의 실제 이용 맥락에서 어떤 정보가 결손되어 있으며, 무엇을 데이터화해야 하는가
- **방법**: ① 시민 현장 프로브(페르소나별 경로 시나리오, 이슈 코딩) ② 전문가 심층인터뷰 주제별 분석(이미 완료: 11테마/38코드/96발화) → 삼각검증으로 데이터 항목 도출
- **기여**: 시설 중심 → 이용자 중심 데이터 스키마 제안, "결손정보의 데이터화"라는 시민데이터 관점
- **투고 후보(탐색 필요)**: 한국방재학회 논문집, 한국안전학회지, 정보화정책, 지역정보화학회지, HCI Korea 학술대회 등 — 8월 중 투고 규정 비교 후 결정
- **준비 사항**: 인터뷰이 연구 활용 동의 확인(논문 인용 범위), 인터뷰 1건 한계 보완 방안(추가 인터뷰 1~2건 또는 사례연구 프레임)
- **일정(안)**: 8월 문헌검토·프레임 확정 → 9~10월 집필 → 11월 투고
