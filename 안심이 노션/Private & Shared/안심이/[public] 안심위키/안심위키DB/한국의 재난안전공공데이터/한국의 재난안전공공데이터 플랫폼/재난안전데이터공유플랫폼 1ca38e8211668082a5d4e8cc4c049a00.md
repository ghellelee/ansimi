A government-run open data portal that provides access to structured and unstructured datasets related to disaster and safety management in Korea. Users can explore data on real-time alerts, shelter locations, disaster types (e.g., typhoons, earthquakes), and daily emergency response reports.

Following is a step-by-step guide for participants on how to find datasets using the [Disaster Safety Data Sharing Platform](https://www.safetydata.go.kr/), including how to use Google Translate to navigate the Korean interface:

1. Go to [https://www.safetydata.go.kr](https://www.safetydata.go.kr/) . Account registration needed to download datasets or use the APIs.
2. Activate Google translation for the page. In Chrome, right-click anywhere on the page and choose **“Translate to English”** or click the **Google Translate icon** in the URL bar if it appears. The page will automatically convert Korean text to English.

[](https://lh7-rt.googleusercontent.com/docsz/AD_4nXdUI0Zeco39dyNjh6jtF-dqB7uGE0gX3n6uv6qoUScHdkAmr1dS1qkiHU-UgGa3ddvRj8pphoQhVuEb8yx_flujcEmBbIKdQ5M7ACOS2qIM_7Sq_ZoWsmIDWFXZkMdfKq_gHpyFTA?key=2m3vzJc6a8gzjAc4WT8osLNC)

1. Click on the popular keywords shown in the center of the homepage to explore trending datasets or Go to “**Finding Data** *데이터 찾기* > **Data List** *데이터 목록*” from the top menu to browse and search datasets directly.

<aside>
⚠️

Please note: The search function on the Disaster Safety Data Sharing Platform only works with Korean keywords. If you're using English, be sure to activate Google Translate first, then search using the translated Korean terms (e.g., “태풍” for “typhoon”, “대피소” for “shelter”).

</aside>
