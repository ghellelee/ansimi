## 비축품

### **가족 구성 입력에 따른 비축품 목록 구성**

- 가족 구성원을 입력 (일반/어린이/아기/애완동물)
- ‘일반’ 가족 중 해당 인원 수를 입력 (노인/생리 용품 이용자)
- 가족 구성에 맞춘 1주일분 비상용품을 확인할 수 있음
    - 앞에서 선택한 가족 구성원에 따라 필요한 비축품의 양과 현재 재고를 표시
    - 중요한 용품은 별표 표시
    - 아기 용품은 별도 목록으로 표시

### **비축품 체크리스트와 쇼핑리스트 연결**

쇼핑 체크리스트 제공 -- 쇼핑 체크리스트에서 체크 표시를 하면 필요한 비축품 목록에 ‘재고 있음’으로 표시되고, 비축품에서 재고 있음 → 사다 또는 재고 없음으로 변경 시 쇼핑리스트에 다시 표시 됨
