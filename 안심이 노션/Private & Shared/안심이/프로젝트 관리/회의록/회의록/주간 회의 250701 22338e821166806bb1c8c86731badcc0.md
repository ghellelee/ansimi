    2. 아이디어는 좋은 것 많았는데 구현하려면…
    3. 전문가 도움 필수적이라는 생각 들었다. 대전에서 우리가 생각한 것 이미 만들어진 모습도 봤고.

    3. 대전에서도 간단. 관련된 기능 6개만 고정. 어르신들이 사용할 수 있도록 교육하려는 탭도 있었다.

### 향후 작업 진행 방향 의견 공유

1. 해피스마일님
    1. 재난가방 만들기 가이드 + 교육
    2. 음식 관련해서 가방 무게… 실제 가방 꾸릴 때는 3일치 정도를 준비하면 된다고.
    3. 물건 어떻게 싸야할지 감이 왔는데, 그런 교육을 할 수 있는 어플.
2. 유나님
    1. 사람마다 다를 수밖에 없고… 표준화할 수 있다면 대피소 이런 개념.
    2. 재난가방 관련된 피쳐 하나로 러프하게 준비. 대표적으로 개인화될 수밖에 없는 영역.
    3. 대피소. 근처 대피소 검색할 수 있는 정도는 준비해보면 어떨까.
    4. 기능적인 게 아직 실체가 없는 상태니까, 뭐라도 이제 구체화해보면 어떨까.
3. 해원님
    1. 재난으로 프로젝트할 때 지적했던 문제 서너가지. 재난의 정의가 다 다르고, 비경험자가 만들 때의 한계, 실질적으로 사용되지 않는 상황의 문제점.
    2. 커스터마이즈된 생존키트 생각해보는 것 좋을 것 같다. 각자가 생각하는 재난에 대해 생각해보는 서비스 제공해도 좋을 것 같다. 재난인식 서비스. 재난에 대해 어떻게 받아들이고, 어떻게 대처하는지… 인식을 향상시킬 수 있는 플랫폼. 
    3. 지금 우리나라 상황에 맞는 방향 고민. 재난에 대한 인식 수준을 높여야. 지역, 생활패턴, 경험 기반의 모듈을 넣으면 어떨까. (기능 개발보다는 컨텐츠 생산?)
    4. 당장 겪을 수 있는 재난이 어떤 종류가 있는지 잘 모르겠다. 큰 범주의 카테고리이기 때문에, 개개인이 겪을 수 있는 재난을 준비할 수 있는 인터랙티브 스토리나 간접 경험 제공.
    5. ‘재난’의 정의 
4. (잠정적) 결론
    1. ‘재난가방 준비하기’
    2. 피그잼에서 재난가방 관련 항목
