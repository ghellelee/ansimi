### 수집 데이터: 사용자 특성 정의를 위해 사용자가 직접 입력해야 하는 데이터들

[수요자 리스트](../../../%5Bpublic%5D%20%EC%95%88%EC%8B%AC%EC%9C%84%ED%82%A4/%EC%95%88%EC%8B%AC%EC%9C%84%ED%82%A4DB/%EC%88%98%EC%9A%94%EC%9E%90%20%EB%A6%AC%EC%8A%A4%ED%8A%B8%201d638e82116680afaf96ed705af5c74e.md) 

| **분류** | **세부 항목** | **수집 이유** |
| --- | --- | --- |
| 기본 정보 | 연령대, 젠더 | 대피소 시설 적합성, 이동 속도, 준비물 다름 (예: 노약자용 아이템) |
| 건강 상태 | 장애 여부, 만성질환 (천식, 당뇨, 심장질환 등), 정신건강, 임신여부 | 대피소 의료 지원 여부 확인, 가방 필수품 결정 (약품, 호흡기, 휠체어 접근성) |
| 가족 구성 | 동반 가족 여부 (영유아, 노약자, 반려동물 포함), 돌봄 상황 | 가방 품목과 대피소 선택 달라짐 (예: 기저귀, 유모차 접근성, 반려동물 동반 가능) |
| 거주지 정보 | 현재 위치 (구/동 단위), 거주 환경 (고층/단독/지하) | 가까운 대피소 매칭, 대피 경로 최적화 |
| 교통 수단 보유 여부 | 차량 보유 여부 | 차량 대피 가능성 판단, 필요한 준비물(연료, 지도 등) 추가 |
| 특수 필요사항 | 언어 지원 필요 여부, 시력/청력 등 감각장애 여부, 외국인인 경우 체류 상황, 범죄 기록 여부, 보험 현황 | 대피소 정보 제공 방식 최적화, 커뮤니케이션 도구 필요 여부 판단 |
