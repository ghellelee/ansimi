### 기대 결과

재난 가방 프로토타입

1. 사용성 평가
2. 콘텐츠 구조 검증
3. 취약계층 맞춤 재난 대비 요구사항, 재난 대비 정보 공백 도출

대피소 데이터

1. 데이터 항목 추가 발굴: 현재 공공 대피소 데이터에 포함되지 않은 정보 요구사항을 식별
2. 데이터 모델 설계: 취약계층 관점의 대피소 데이터 모델을 정의
    - 수집된 데이터 기반으로 분류+확장
3. 데이터 현황 분석: 데이터 공백 분석을 통해 공공데이터 구조의 한계와 개선 필요 영역을 도출
4. 수집 가능성과 우선순위 도출: 우선적으로 개선해야 할 데이터 항목을 도출
5. 데이터 기반 서비스 시나리오 도출: 데이터 기반 재난 대비 서비스 설계 방향을 제시
6. 공공데이터 개선 및 정책 제안 도출
